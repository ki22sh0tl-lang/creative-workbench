# UI 自检记录

日期：2026-10-03

本次范围：首页与工作台公共视觉系统；保留既有业务字段、标签分类、数据计算和路由。

| 维度 | 完成的调整与检查 |
| --- | --- |
| 排版 | 首页保留指定的两行标题；工作台缩小宣传标题，统一模块标题和数值层级。 |
| 留白 | 首页增加标题与操作之间的空间；后台收紧侧栏和总览，数据卡片前置。 |
| 视觉层级 | 批次概览、业务计数、流程、待办依次呈现；标签父类标题与子标签分层。 |
| 色彩 | 炭黑底、灰阶面板、浅玫瑰色主操作；保留状态色与可见焦点。 |
| 动效 | 短暂淡入、按钮按压与悬停反馈；没有持续播放动画。 |
| 微交互 | 多选项提供明确的选中背景；弹窗保留底部操作；增加返回首页入口。 |
| 响应式 | 320 / 375 / 768 / 1024 / 1440 像素，首页、总览、标签、选题、数据、复盘共 30 组检查，无整页横向溢出。宽表格保留容器内滚动。 |
| 原创性与适配 | 沿用该产品既有深色品牌，围绕内容实验链路重排；使用当前工作台真实截图，没有仿造其他项目页面。 |

## 验证

- Edge / Playwright 页面检查：没有捕获到 JavaScript 页面异常。
- 手机弹窗：修复关联案例复选框继承全宽输入框样式导致标题竖排的问题；案例选择、Esc 关闭通过。
- 减少动态效果设置：动画关闭；键盘 Tab 首个焦点为跳转主要内容链接。
- `npm run check`：2 项 API / 工作流测试通过。
- `npm run check:ui`：前端语法检查通过。
- `git diff --check`：通过。

以上为本次已检查环境中的结果，不代表获得奖项认证，也不替代真实用户可用性测试。未调用收费 AI 接口，未变更其业务逻辑。
